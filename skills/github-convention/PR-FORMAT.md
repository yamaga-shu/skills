# AI エージェント用 PR 本文テンプレート

AI が PR を作成するときは、以下の構成に従って本文を組み立てる。
人間が PR を書く際にこの構成に従う必要はない。

各節の `<!-- -->` は記入の指針であり、本文には残さない。
該当しない節は節ごと削除してよい。

---

## 背景

<!-- なぜこの変更が必要なのか。解決したい課題や、変更前に何が問題だったか。 -->

## 変更内容

<!-- 何をしたか。差分を追わなくても全体像が掴める粒度で。 -->

## 検討したこと

<!-- 判断に迷った点、採らなかった選択肢とその理由。レビュアが「なぜこの実装なのか」を問わずに済むようにする。 -->

## 確認方法

<!-- 動作を確認した手順、テストの結果など。読んだ人が同じ確認を再現できる粒度で。 -->

## 実行したコマンド

<!-- 一度実行すればもう繰り返されない操作を行った場合、叩いたコマンドをそのまま残し、そう組み立てた理由を添える。
     例えば、クラウド上の資源を最初に一度だけ手で作るような操作が該当する。
     該当しなければ節ごと削除する。 -->

Closes #<!-- 対応する issue の番号。issue がなければこの行ごと削除する。 -->
